## 当前方案

```text
设计稿原图 → 多模态设计说明 design-spec.md
设计说明 + PRD + 仓库规范/源码 → 开发计划 → 编码工具调用
→ 独立编译/构建 → 本地任务分支、代码差异与应用预览
```

识图和编码均通过用户现有的 API key，经 GLM Coding Plan 兼容入口调用 `glm-5.3-flash`。`VISION_MODE=remote`，不再调用 OCR 或 Swift。原图以图片消息提交；设计说明描述区域、控件、可见状态、样式、文字和不确定处，交互以 PRD 为准。

根据 [官方文档](https://docs.z.ai/guides/vlm/glm-5.3-flash)，启用思考并使用低推理强度。客户端保留 `reasoning_content`，避免连续工具调用时被标准 OpenAI 消息转换丢弃。识图失败停止任务并保留错误，不自动重试或回退 OCR。

## 验证边界

识图会存在估计和误识，例如本次模型将圆角方形头像描述为圆形；不能将其输出当作精确像素测量。开发按 PRD 复用现有样式。本次未做像素级比对，也未重跑 PRD 全部新增、编辑、持久化用例。

后台仍只自动执行编译与构建，交付报告中的浏览器和视觉项保留 `not_run`，额外检查记录在本文。旧 OCR 任务记录不重写；尚未加入自动浏览器截图、视觉评分或自动视觉修复循环。
