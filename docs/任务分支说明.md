# 任务分支说明

远程公开仓库使用统一目录结构。`main` 包含 Agent、CRM 基线、mock、原型和设计资料；以下任务分支在相同目录结构下保留已完成需求，便于比较 CRM 的源文件。

| 分支 | 需求 | 原本地 CRM 提交 |
| --- | --- | --- |
| `design-agent/t-c4764bfc713f` | 客户状态筛选 | `126d0fa` |
| `design-agent/t-ccc4f33ae39d` | 客户关键词搜索 | `4ff56e3` |
| `design-agent/t-5994fefa6218` | 多模态识图升级后的客户关键词搜索 | `16f84a1` |

这些分支是将原本地任务的源文件差异应用到公开仓库的 `customer-manager/` 目录后重新提交的，因此远程提交 SHA 与上表中的原提交不同。原本地仓库、worktree 和 Git 历史继续保留。

在 GitHub 选择 **Compare**，以 `main` 为 base，以某个任务分支为 compare，可以直接查看代码改动。例如：[最近任务的代码对比](https://github.com/BruceZM/design-agent-mvp/compare/main...design-agent/t-5994fefa6218)。

远程仓库不包含 API Key、`.env`、原始凭据文件、运行日志、历史上传材料、任务数据库、依赖目录和构建产物。失败任务保留在原本地运行目录，未作为成功成果发布。

新克隆项目默认从 `main` 初始化本地 CRM 基线。如果希望以某个成果作为新的演示基线，请在首次运行初始化脚本前选择对应的远程任务分支。已经初始化的本地 CRM 有独立历史，外层切换分支会影响它的工作目录，应先检查并保存已有改动。
