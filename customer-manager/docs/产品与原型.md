# 客户管理 MVP

本项目是 Design Agent 的固定下游仓库。基线只包含客户列表、分页、客户详情、新增与编辑；使用虚构演示数据与浏览器 localStorage，不接入真实客户资料、登录或服务端数据库。

## 页面和交互

桌面主界面采用窄侧栏 + 顶部操作区 + 客户表格。表格字段为客户、公司、联系方式、跟进状态、最近更新，点击客户打开右侧详情抽屉。新增和编辑共用表单；客户名称必填，联系人、公司、电话与备注可选。保存失败或字段错误保留输入；保存成功即时刷新列表，刷新页面后保留修改。

手机界面收起侧栏，将表格替换为客户卡片，详情抽屉占满可用宽度。列表每页 8 条，展示空状态和分页边界。键盘 Esc 关闭抽屉，打开时移动焦点，关闭后恢复焦点。

状态固定为「待联系」「跟进中」「已成交」。基线刻意不做状态筛选，留作后续 Agent 的第一项增量验收：添加状态筛选、重置、筛选变化回到第 1 页，保持新增编辑和数据持久化正常。

## 设计顺序

1. `prototype.html`：可交互的低保真原型，确认列表与抽屉布局。
2. `ui/`：以原型截图为参考，通过内置 imagegen 生成列表和编辑状态 UI 稿；具体模型版本不可确认。
3. React 实现：以 UI 稿为视觉参考，字体、间距、表单和状态颜色以可用性为准，生成图中文字不作为产品字段事实。

## 视觉约定

主色为深青绿 #0f766e，背景 #f4f7f7，正文 #172b2a，使用系统中文字体。表格保留细分隔线、状态标签和充足留白，不加入无业务意义的仪表盘。顶部说明数据保存在当前浏览器。
