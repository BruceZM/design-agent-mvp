# 青禾 CRM：客户关键词搜索

需求编号：MOCK-CRM-002  
版本：1.0  
日期：2026-10-01  
目标仓库：项目内 `customer-manager`，基准分支 `main`  
材料配对编号：feature-1  
配套设计稿：[feature-ui-1.png](../ui/feature-ui-1.png)

## 1. 背景与目标

现有客户档案支持客户列表、每页 8 条分页、详情、新增、编辑和 localStorage 持久化，但没有关键词搜索。客户数量增多后，用户需要逐页查找客户。

本次只增加客户关键词搜索，让用户通过姓名、公司或手机号快速找到客户。沿用现有青绿色风格、列表和手机卡片布局。

## 2. 需求范围

在现有客户列表卡片中，标题区域下方、表格上方新增一行搜索工具栏：

- 搜索输入框：可见标签或无障碍名称为「搜索客户」，占位文字为「搜索姓名、公司或手机号」，左侧放搜索图标。
- 输入框右侧添加「清空搜索」按钮。
- 桌面上显示辅助文字「按姓名、公司或手机号搜索」。
- 不增加提交搜索按钮，输入时立即更新列表。

不新增状态筛选、排序、批量操作、登录、后端、数据库或外部请求。本需求以 `main` 的客户列表为起点，不依赖其他任务分支的状态筛选功能。

## 3. 搜索与分页规则

1. 默认搜索框为空，显示全部客户；列表标题保持「全部客户」，数量为全部客户数。
2. 使用输入内容去除首尾空白后的字符串作为关键词。只输入空格时等同于未搜索。
3. 对客户姓名 `name`、公司 `company`、手机号 `phone` 分别进行子串匹配；任一字段匹配即命中。英文字母匹配忽略大小写，中文照常匹配；手机号按字符串处理。不做拼音、分词、多关键词组合或正则匹配。
4. 没有公司或手机号时按空字符串处理，不报错。不得搜索备注、状态或更新时间。
5. 搜索只改变当前列表展示，不修改原始客户数据，不向 localStorage 写入搜索状态。刷新后恢复空搜索。
6. 有有效关键词时，列表标题改为「搜索结果」，数量为命中客户数。分页文案与页数也根据命中数量更新，仍每页 8 条，沿用客户原有顺序。
7. 每次编辑搜索内容或点击「清空搜索」都回到第 1 页。空搜索时「清空搜索」禁用；点击清空后输入框重新获得焦点。
8. 搜索结果随客户新增或编辑即时更新。如果数据变化令当前页超出总页数，调整到有效页，不能留下空白页。
9. 0 条结果时按 1 / 1 页展示，上一页、下一页均禁用。

## 4. 无结果与原有空列表

有有效关键词但 0 条命中时，不展示客户行或手机客户卡片，显示：

- 标题：「没有找到匹配的客户」
- 提示：「试试其他姓名、公司或手机号，或清空搜索。」
- 操作：「清空搜索」，点击恢复全部客户并回到第 1 页。

没有任何客户、且搜索为空时，保留现有「还没有客户」及新增客户提示。

## 5. 视觉与手机要求

- 设计稿展示搜索「青禾」后的桌面状态：列表标题「搜索结果」、数量 6、六位青禾科技客户、1 / 1 页。图片中的姓名和联系方式都是测试数据。
- 页面整体布局、品牌、标题、侧栏、新增客户按钮、表头和状态标签保持现有风格。沿用 `#0f766e` 主色、`#f4f7f7` 页面背景、白色列表卡片和细边框。
- 桌面工具栏位于列表标题和表头之间，左右留白与现有列表一致；输入框约 360px 宽、40px 高、圆角 6–8px，清空按钮使用次级按钮样式。
- 720px 及以下沿用客户卡片视图，搜索工具栏可换行。320px 宽时输入框与清空按钮不得造成页面横向溢出，可让输入框占一行，清空按钮换行。
- 搜索控件支持键盘操作，输入框有明确名称，焦点样式可见；不改变输入时的焦点。
- 设计稿用于布局和视觉参考；交互、边界行为及精确文案按本 PRD 执行。生成图若出现文字误差，不照搬错误文字。

## 6. 实现约束

- 复用现有 `CustomerList`、`Customer` 类型和现有样式；只修改 `src/` 下的必要文件。
- 不新增依赖，不修改种子数据、构建配置或脚本，不调用外部服务。
- 原有新增、编辑、详情和客户数据持久化继续正常工作；不将“搜索结果”覆盖为原始客户数据。
- 保持 TypeScript 严格类型，不用 `any` 掩盖错误。

## 7. 验收用例

下表以全新的浏览器存储、仓库原始 24 条种子客户为前提。测试新增或编辑后，数量按实际客户数据计算。

| 编号 | 操作 | 预期结果 |

| AC-02 | 输入「青禾」 | 「搜索结果 6」，六位客户均属于青禾科技，1 / 1 页 |

| AC-06 | 在未搜索的第 3 页输入「青禾」 | 立即回到第 1 / 1 页，显示 6 位，不出现空白页 |
| AC-07 | 输入「不存在的客户」，再点击空状态中的清空按钮 | 先显示 0 条、无结果提示和禁用分页；清空后恢复 24 位、第 1 / 3 页 |
